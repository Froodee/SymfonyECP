# ECP — Plateforme e-commerce (Symfony)

Application web e-commerce développée dans le cadre d'un projet de BTS SIO SLAM, 
basée sur une situation professionnelle réelle.

## Stack technique
- PHP / Symfony
- Doctrine ORM
- Twig
- MySQL
- Docker

## Fonctionnalités
- Catalogue produits avec gestion des stocks
- Système d'authentification et rôles utilisateurs
- Architecture MVC
- Interface responsive

## Lien avec ecpv2
Ce projet partage sa base de données avec [ecpv2](https://github.com/Froodee/ecpv2), 
une application de bureau C# (MVVM) permettant la gestion interne des données.
